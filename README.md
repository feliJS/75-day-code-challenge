## 👋 Welcome!

**75 Days of Code** is an open-source collection of 75 independent coding challenges designed to help developers practice their programming skills, explore new languages, and build something fun.

**No weather apps or pomodoro timers!!!**

This is for anyone that is just starting out with coding, building their portfolio or wanting some unique projects to work on!

Inspired by Advent of Code, each challenge presents a problem for you to solve in in your own way!

**Any programming language or framework is welcome.** Your solution can be a website, a terminal application, or something entirely different! (maybe even a game in unity!? 👀)

## 🚀 Getting Started

1. **Choose a challenge** — Browse the [Issues](https://github.com/feliJS/75-day-code-challenge/issues) tab or explore the `challenges/` folder.
2. **Fork this repository** — Create your own copy.
3. **Build your solution** — Use any language, framework, or approach you like.
4. **Submit a Pull Request** — Reference the original challenge using `Related to #ISSUE_NUMBER`.
5. **Share your work** — Comment on the original issue with a link to your submission.

> [!IMPORTANT]
> Challenge Pull Requests are used to showcase solutions and practice contributing on GitHub. **They will not be merged into the main repository.** Your code stays in your own fork.
>
> Don't want to create a Pull Request? You can also share a link to your solution directly in the challenge's comments!

## 🎯 Your Challenge, Your Difficulty

There are no fixed difficulty levels here.

Every challenge has a set of core requirements, but how you approach them is entirely up to you.

Keep it simple, experiment with something new, or challenge yourself to go further!

- Complete challenges in any order.
- Use any programming language.
- Add your own creative features.
- Take as much time as you need.

**75 days is just the name. There's no daily deadline or streak requirement!**

## 🧩 Explore the Challenges

All 75 challenges will be available in two places:

- **[Issues](https://github.com/feliJS/75-day-code-challenge/issues)** — Browse challenges, ask questions, and share your solutions.
- **`challenges/`** — Explore the challenge descriptions and requirements.

Each challenge includes a goal, a set of requirements, and optional bonus ideas.

New challenges will be added until the collection reaches 75!

## 📤 Submitting Your Solution

Ready to share what you've built?

1. Fork this repository.
2. Create a folder in your fork following this structure: `submissions/challenge-XX/your-username/`
3. Add your solution and a short README explaining how it works.
4. Open a Pull Request to this repository.
5. Title your PR something like `Challenge #01 - Password Generator`.
6. Include `Related to #ISSUE_NUMBER` in your PR description.
7. Link your submission in the original challenge issue.

**Please note:**
- Challenge submissions will not be merged.
- Challenge issues will remain open for everyone.
- Never include passwords, API keys, or sensitive information in your submissions.

## 🤝 Contributing

Everyone is welcome to participate, regardless of experience!

This repository is focused on providing 75 original coding challenges. New challenge issues are created by the maintainer only.

If you have feedback, questions, or suggestions, feel free to leave a comment on the relevant challenge or start a Discussion.

Please keep all interactions friendly, supportive, and respectful.

I've always wanted to find fun programming challenges that go beyond the usual weather apps, calculators, and Pomodoro timers.

So I decided to create my own collection!
