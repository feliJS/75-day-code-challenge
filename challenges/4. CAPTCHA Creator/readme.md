# Challenge 04: CAPTCHA Creator 🤖

Are you human? Prove it!

Build your very own CAPTCHA generator that creates randomized challenges for users to complete.

Instead of relying on an existing CAPTCHA service, **design your own verification challenges from scratch!**

## 🧩 Your Challenge

Create an application that generates random verification challenges and checks whether the user's answer is correct.

### Requirements
- Generate a random CAPTCHA challenge.
- Display the challenge to the user.
- Allow the user to submit an answer.
- Check whether the answer is correct.
- Display a success or failure message.
- Generate a new challenge after completion.
- Provide a way to refresh or skip the current challenge.

### ✨ Bonus Ideas
- Support different types of challenges, such as math problems, text recognition, or image matching.
- Add a countdown timer.
- Introduce difficulty settings.
- Track how many challenges the user has completed.
- Add accessibility-friendly alternatives.
- Include animations or sound effects.

## 💡 Example

**Generated challenge:**

```text
What is 7 + 4?
```

**User input:**

```text
11
```

**Result:**

```text
✅ Verification successful!
```
