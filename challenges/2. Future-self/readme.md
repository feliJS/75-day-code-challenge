# Challenge 02: Digital Time Capsule 💌

What would you tell your future self?

Build a digital time capsule that lets users write messages today and reveal them at a future date!

## 🎯 Your Challenge

Create an application where users can save messages that remain hidden until a chosen date.

### Requirements
- Allow users to write a message.
- Let users choose a future unlock date.
- Save the message and its unlock date.
- Hide the message content before the unlock date.
- Allow users to read their message once the date has arrived.
- Display all saved time capsules and their unlock status.
- Make sure capsules can be retrieved after restarting the application.

### ✨ Bonus Ideas
- Add a countdown until each capsule unlocks.
- Allow users to attach images.
- Add custom themes or virtual envelopes.
- Send optional notifications when a capsule unlocks.
- Allow users to write a reply to their past self.

## 💡 Example

**Capsule created:** January 1, 2027

**Unlock date:** January 1, 2028

Before the unlock date:
```text
🔒 Your message is locked!
Opens on January 1, 2028.
```

After the unlock date:
```text
💌 A message from your past self!

"Hey future me! I hope you're doing well!"
```
