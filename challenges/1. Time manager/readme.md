# Challenge 01: When Was The Last Time? ⏳

Ever wondered when you last cleaned your room or changed your bedsheets?

Build a tracker that remembers **when you last did something** and tells you how much time has passed since then!

## ❄️ Your Challenge

Create an application that lets users track events or activities and see how long ago they last happened.

### Requirements
- Allow users to add activities they want to track.
- Store the date when each activity last happened.
- Display how many days have passed since that date.
- Allow users to update an activity's date.
- Allow users to remove activities.
- Make sure tracked data can be retrieved when the application is reopened.

### ✨ Bonus Ideas
- Display messages such as "3 days ago" or "2 weeks ago".
- Let users set a reminder interval for each activity.
- Highlight activities that haven't happened in a while.
- Show a history of previous dates for each activity.
- Add categories, colors, or custom icons.

## ☃️ Example

| Activity | Last Done | Time Passed |
|---|---|---|
| Changed bedsheets | 3 days ago | 3 days |
| Watered plants | Today | 0 days |
| Cleaned keyboard | 14 days ago | 14 days |
