# Challenge 03: Sound Detective 🔊

How good are you at recognizing sounds?

Build a guessing game where players listen to a sound (or music?) and try to identify what produced it!

## 🕵️ Your Challenge

Create a game that challenges players to identify sounds using audio clues.

### Requirements
- Provide a collection of at least five different sounds.
- Play one randomly selected sound per round.
- Let players choose or enter what they think the sound is.
- Check whether the answer is correct.
- Keep track of the player's score.
- Avoid repeating the same sound within a game session.
- Display the final result after all rounds are completed.
- Allow players to start a new game.

### ✨ Bonus Ideas
- Add multiple difficulty levels.
- Let players replay each sound a limited number of times.
- Create themed sound collections.
- Add a countdown timer for each round.
- Provide hints after incorrect guesses.
- Include a streak bonus for consecutive correct answers.

## 💡 Example

**Round 1 of 5**

```text
🔊 Playing sound...

What do you hear?

A) Rain
B) A keyboard
C) A train
D) A dog barking
```

**Player selects:** B

```text
✅ Correct!

Score: 1/1
Next round...
```

*Example only. You decide which sounds and answer formats to use.*
